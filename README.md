**Kata  TDD y pytest**
primero crea el entorno virtual y activalo
    python3 -m venv venv
(primero tienes que estar en la ruta en la que deseas hacer tu entorno)
despues lo activas 
        'source venv/bin/activate'
despues haces un 'pip list' y 'pip instal ipykernel'

Cuando ya tiene tu entorno virtual, tienes que bajar la extension de python, su compilador y la extension pytest para ejecutar los test debidamente
